# Weather Forecast App

Full-stack application for getting weather forecast for a selected location.


## Stack

- **Frontend:** Angular
- **Backend:** Express + TypeScript
- **Database:** PostgreSQL + TypeORM
- **Infra:** Docker, GitHub Actions, Nginx
